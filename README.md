# 🏎️ Formula 1 Data Analysis using Python

A data analysis project built using Python, Pandas, and Matplotlib to explore historical Formula 1 race data. The project analyzes driver and constructor performance, championships, podium finishes, pole positions, circuits, and several other interesting Formula 1 statistics through data manipulation and visualization.

---

## ✨ Features

- 🏆 Driver with the most race wins
- 🏎️ Constructor with the most race wins
- 👑 Drivers with the most championships
- 🥇 Constructors with the most championships
- 🥉 Drivers with the most podium finishes
- ⚡ Drivers with the most pole positions
- 🌍 Most frequently used Formula 1 circuits
- 🌎 Countries that hosted the most races
- 📊 Pole Position vs Race Wins analysis
- 🔥 Lewis Hamilton vs Max Verstappen (2021 Season)

## ▶️ How to Run

1. Clone the repository.

```bash

```

2. Install the required libraries.

```bash
pip install pandas matplotlib
```

3. Open the notebook.

```bash
jupyter notebook
```

4. Run all notebook cells.
